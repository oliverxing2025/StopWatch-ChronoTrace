# 时迹 ChronoTrace 隐私说明

生效日期：2026 年 8 月 26 日

## 数据处理概览

ChronoTrace 不要求账号，不包含广告或行为统计模块。自绘图形、麦克风音频和粒子
播放内容不会上传。麦克风样本仅在设备内存中实时处理，用于音乐律动。

## 本地保存的数据

设备可能在 NVS 中保存：

- Wi-Fi 名称和密码；
- 语言、亮度、音量、震动和连接开关；
- 用户自绘图形及颜色；
- 天气模式、城市、经纬度和最近一次天气缓存。

当前固件没有启用 Flash Encryption，因此获得设备物理访问权限的人可能读取未加密的
本地 Flash。不要在不受信任的设备上保存敏感 Wi-Fi 凭据。

Wi-Fi 配网页面会按设计以明文显示密码，便于保存前核对。请只在私密环境中使用，
避免周围人员、摄像头或屏幕共享软件看到密码。

## 联网功能

启用 Wi-Fi 和天气后：

- 自动城市模式向 `ipwho.is` 请求由公网 IP 推断的近似城市和经纬度；
- 手动城市模式向 Open-Meteo 地理编码服务发送用户输入的城市名称；
- 天气服务向 Open-Meteo 发送经纬度，获取当前天气和当日温度范围。

这些服务会像普通网络服务一样看到请求来源的公网 IP，并受其各自隐私政策约束。
ChronoTrace 不运营上述第三方服务。

## Bluetooth

Bluetooth 用于接收时间校准数据。固件不会通过 Bluetooth 发送自绘图形、Wi-Fi
密码或麦克风音频。

## 用户控制

- 可在设置中关闭 Wi-Fi、天气或 Bluetooth。
- 可在图形界面删除自绘内容。
- 只有包含 NVS 擦除的恢复流程才能确保移除 ChronoTrace 本地数据；只重写应用
  不一定会清除 NVS。擦除也可能删除设备上的其他数据，请先确认恢复和备份方案。

安全问题请使用 GitHub 的私密漏洞报告功能；隐私问题请通过正式发布页或开发者
公告中列明的渠道联系开发者。
