# ChronoTrace iOS 商业化产品蓝图

## 1. 文档定位

本文档定义 ChronoTrace 在当前硬件版开发完成后的 iOS 移植方向、免费/高级功能边界与 App Store 商业模式。

当前阶段不开始 iOS 工程，不向现有 StopWatch 固件加入付费墙，不限制硬件版的任何现有功能。硬件版继续作为完整的产品与视觉行为标杆。

## 2. 产品定位

### 产品名称

- 中文名：时迹
- 英文名：ChronoTrace
- 副标题方向：把时间装进真实流体里
- 英文副标题方向：Time, formed by living particles

上架前必须对中英文名称、图标和品牌资产进行商标及 App Store 同名检索。

### 核心价值

ChronoTrace 不是另一个普通秒表，而是一个由真实重力、手势和声音驱动的流体时间艺术工具。用户在首次打开后 60 秒内应能完成一次完整的核心体验：

1. 倾斜手机，看到粒子像流体一样受重力影响。
2. 点按屏幕，粒子自然松散后重组成当前时间。
3. 触摸或滑动粒子，获得可立即理解的视觉和声音反馈。

## 3. 商业模式

### 基本模型

- App 免费下载。
- 不插入广告。
- 不设置自动续费订阅。
- 以一次性非消耗型内购解锁「ChronoTrace 完整版」。
- 中国大陆标准价格：¥29.90。
- 其他地区使用 App Store 的地区化对等价格，上架前再审核各区价格。
- 必须提供「恢复购买」，不要求用户注册账号才能使用或恢复完整版。

### 商业原则

- 先让用户体验核心魔力，再展示付费页；首次启动不冷启动付费墙。
- 免费版是可持续使用的完整体验，不设倒计时试用期，不制造焦虑式弹窗。
- 付费点主要是「更强的表达能力和更完整的沉浸体验」，不是修复人为设置的基础功能残缺。
- 解锁成功后不再展示任何付费提示。

## 5. 付费页设计

### 出现时机

只在以下情况显示：

- 用户主动选择带锁完整版功能。
- 用户已经完成至少一次粒子时钟组字，然后主动打开「全部主题」。
- 用户在设置中主动点击「解锁完整版」。

不在首次启动、正在运行倒计时、权限申请之前或用户刚拒绝权限时弹出。

### 付费页文案结构

- 标题：解锁完整的时迹
- 副标题：一次购买，永久使用，无广告、无订阅
- 三项核心收益：全部粒子主题；完整手写与模拟表盘；天气与音乐响应
- 主按钮：¥29.90 永久解锁
- 次按钮：继续使用免费版
- 底部操作：恢复购买、隐私政策、使用条款

价格文案必须从 StoreKit 返回的地区化价格产生，不在界面中写死人民币数值。

## 6. 权限与隐私设计

- 加速度计/陀螺仪：用于倾斜、重力和晃动粒子；在首次进入流体互动时说明。
- 麦克风：只在用户主动打开「音乐响应」后申请；默认关闭；不保存、不上传音频。
- 位置：只在用户打开粒子天气时申请「使用 App 时」权限；允许大致位置。
- 位置拒绝时：允许手动选择城市，或继续使用上次缓存。
- 手写：默认仅保存在设备本地，不做 OCR，不上传。
- 购买状态：由 StoreKit/App Store 负责，不自建用户账号。
- 首发版不接入广告 SDK 和跨 App 追踪 SDK。

## 7. iOS 交互映射

StopWatch 上的 A/B 物理按键不在 iPhone 上按位置照搬。所有行为应先转换成平台无关的「用户意图」，再映射到 iOS 的手势和控件。

| 当前意图 | iOS 首发交互 |
| --- | --- |
| 展示当前时间 | 单击流体区 |
| 数字/模拟时钟切换 | 时钟形成期间双击 |
| 保持/释放时钟 | 长按流体区 |
| 流体阵风 | 左右滑动 |
| 音量调节 | 系统音量和设置滑杆，不占用竖向滑动 |
| 手写 | 底部轻量工具栏进入，编辑完成后回到流体 |
| 倒计时 | 底部轻量工具栏进入环形选择器 |
| 更换主题 | 左上角主题按钮或设置面板 |
| 天气 | 流体主屏向左滑入，保留快捷「返回流体」手势 |

所有可识别粒子编队的切换必须延续 ChronoTrace 行为标杆：先释放到真实流体，留出约 600–700 ms 可见的松散过程，再组成新形状。

## 8. 为未来移植预留的当前开发原则

未来新增固件功能时，在不破坏现有 ESP-IDF 实现的前提下，尽量保持以下边界：

1. 粒子求解器不直接读取按键、触摸、Wi-Fi 或 NVS。
2. 编队定义使用归一化坐标或与屏幕尺寸无关的几何参数。
3. 硬件按键和手势先生成「打开手写」、「切换主题」、「释放编队」等意图，不在输入层内直接改写粒子状态。
4. 时间、天气、存储、麦克风和位置作为可替换服务，其输出数据结构不依赖 ESP-IDF 类型。
5. 主题颜色、粒子数量、转场时间和音景映射集中管理，避免散落在平台层。
6. 主要行为建立固定输入/输出测试样例，便于 iOS 版与硬件版对照。

这些原则是新功能的架构指导，不授权为了移植而对当前稳定固件做大规模重构。

## 9. iOS 移植启动条件

以下条件全部满足后，再开始 iOS 移植：

- StopWatch 版核心功能进入一个可明确命名的稳定版本。
- 所有最终手势、粒子编队、音效和主题已在真机上验收。
- 录制数字表、模拟表、手写、倒计时、天气及主题切换的黄金参考视频。
- 整理所有品牌、字体、图标、音频和上游代码的许可清单。
- 完成 ChronoTrace/时迹名称及图标的 App Store 和商标冲突检索。
- 准备 Apple Developer 账号、付费 App 协议、税务和银行资料。

## 10. 移植实施路线

### 阶段 A：忠实原型

- SwiftUI 应用外壳。
- 保留 C 粒子求解器，建立轻量桥接层。
- Metal 负责全屏粒子渲染。
- Core Motion 提供重力、姿态和晃动数据。
- 首先复现流体、数字时钟和 600–700 ms 释放转场。

### 阶段 B：完整功能

- 模拟表盘、手写、倒计时、全部主题、天气、环境音和麦克风响应。
- 适配 iPhone 与 iPad 的竖屏/横屏和安全区。
- 倒计时在 App 退到后台后通过系统通知保证结果正确，不伪装持续运行流体。

### 阶段 C：商业化与发行

- StoreKit 2 非消耗型内购、恢复购买和断网权益缓存。
- 隐私清单、权限文案、隐私政策和使用条款。
- App Store 图标、截图、10–20 秒核心体验预览视频和中英文元数据。
- TestFlight 内测，再根据付费页到达率、购买转化与崩溃数据决定首发。

Apple Watch、Mac、Vision Pro 和锁屏小组件不进入首发必做范围，待 iPhone/iPad 版的留存和付费意愿被验证后再决定。

## 11. 首发验收指标

### 产品质量

- 主流支持机型上前台连续运行 30 分钟无崩溃、无明显内存增长。
- 常用机型保持流畅粒子表现；性能不足时自动降低粒子密度，不改变编队语义。
- 数字、模拟表盘、手写和天气的所有可识别形状均由真实粒子形成，不用静态覆盖层替代。
- 从一个可识别编队转到另一个时，先有 600–700 ms 真实流体释放。
- 拒绝麦克风或定位权限后，主体 App 仍然可正常使用。

### 商业验证

- 首次启动到完成第一次粒子时钟的中位时间不超过 60 秒。
- 付费页展示前，用户已经体验至少一次真实粒子编队。
- 购买失败、取消和断网不丢失当前作品或计时状态。
- 恢复购买能在全新安装上正确恢复完整版权益。
- 购买与恢复流程通过 StoreKit 测试和 TestFlight 真实沙盒验证。

## 12. 首发传播素材方向

首个 App 预览片不先解释功能，而是在前 3 秒展示不可替代的视觉时刻：

1. 手机倾斜，粒子流体滑向屏幕一侧。
2. 粒子自然散开，随后组成当前时间。
3. 手写「时迹」后，粒子依次组成两个字。
4. 快速切换黄金、钻石、极光三种高识别度主题。
5. 以「一次解锁·无广告·无订阅」收尾。

所有宣传截图和视频必须来自实际 App 运行画面，不用概念图代替真实产品效果。
