# 时迹 ChronoTrace 使用指南

适用版本：`1.0.0`
适用设备：M5Stack StopWatch

## 1. 快速开始

开机后，粒子会落入屏幕下方形成粒子池。转动设备时，粒子会根据重力方向自然流动。
首次使用可先长按 A + B 打开设置，选择语言，并按需调整亮度、音量、震动、
音乐律动、Wi-Fi、天气城市和 Bluetooth 校时。

设备内置简版说明：进入“设置 → 使用指南”。指南包含“按键、触控、图形、设置”
四页，可左右滑动切换，也可用 A / B 键前后翻页。

## 2. 实体按键

| 输入 | 功能 |
| --- | --- |
| A 键短按 | 打开或退出自绘编辑器。 |
| A 键双击 | 打开或关闭倒计时。 |
| A 键长按 | 切换粒子密度。 |
| B 键短按 | 切换粒子主题。 |
| B 键双击 | 查看电量与充电状态。 |
| B 键长按 | 开启或关闭音乐律动。 |
| A + B 同时长按 | 打开或关闭设置。 |

在内置使用指南中，A / B 键用于前后翻页；长按 A + B 可退出指南或设置。

## 3. 默认界面与粒子时钟

| 手势 | 功能 |
| --- | --- |
| 点击 | 粒子组成当前时间。 |
| 长按 | 开启或关闭常显粒子时钟。 |
| 双击 | 时钟显示时切换数字钟 / 模拟钟；其他时候随机显示图形。 |
| 向左滑 | 打开粒子天气。 |
| 向右滑 | 进入图形模式。 |
| 向上 / 向下滑 | 提高 / 降低音量。 |

时间数字变化时，会保留可以继续使用的粒子；粒子不足时从周围补充，多余时才自然
掉落。模拟钟中各指针粒子的显示尺寸保持一致。

## 4. 倒计时

双击 A 键进入倒计时，选择 1–60 分钟后开始。运行期间点击可暂停或继续，双击可退出。
数字变化同样遵循“保留够用的粒子、不足补充、多余掉落”的规则。倒计时结束时会有
声音与粒子反馈；若听不到声音，请检查设备设置中的音量及声音开关。

## 5. 图形与动画

从默认界面向右滑进入图形模式：

- 左右滑动：切换图形页。
- 向下滑动：从图形选择切换到动画选择。
- 向上滑动：从动画选择返回图形选择。
- 点击图形：按点击顺序加入播放列表。
- 长按：播放已选图形；未选择时可直接预览当前项目。
- 双击默认画面：随机显示一个图形。

图形和动画由当前粒子池中的粒子组成。一个图形或动画正在运行时，各组成部分不会
互相借用粒子，以减少断裂和粘连。动画包括方向箭头、呼吸心跳、DNA 双螺旋、烟花、
粒子雨以及横向滚动的 “I LOVE YOU”等效果。

## 6. 自绘图形

按 A 键或在图形选择页点击“自绘”进入编辑器。可从屏幕两侧选择颜色，在中央区域绘制。
设备最多保存 12 个自绘图形。

- 返回：退出编辑器并返回上一界面。
- 删除：删除当前自绘图形。
- 下一个：切换到下一个保存位置。
- 确定：保存当前图形。

内置图形不能删除；删除功能仅用于用户自绘内容。

## 7. 音乐律动

长按 B 键，或进入“设置 → 设备设置”开启音乐律动。开启后，麦克风只在设备本地分析
节奏；低频、中频和高频会推动不同层次的粒子产生波动、上蹦和火花。若只有颜色变化
而没有明显跳动，请提高外部声音音量、让声源靠近设备，并确认麦克风没有被遮挡。

## 8. 电池与充电

双击 B 键查看电量。充电时，电池下方会由粒子逐个组成一条与电池等长的线；完整后
散落，再重新组成。若刷机完成后屏幕暂时未响应，请等待设备启动；不要反复插拔，
必要时只重启一次设备。

## 9. Wi-Fi、天气与时间校准

进入设置后可配置：

- Wi-Fi：点击未连接状态后进入网络搜索和连接界面。
- 天气：可自动定位近似城市，也可手动输入城市并刷新天气。
- Bluetooth：用于与手机进行时间校准。

联网和隐私细节见[隐私说明](PRIVACY.zh-CN.md)。Wi-Fi 密码、自绘图形和设置保存在
设备本地；麦克风音频不会上传。

## 10. 设置与关于

长按 A + B 打开设置。可调整语言、Wi-Fi、天气城市、Bluetooth 校时、亮度、音量、
震动、音乐律动，并打开使用指南和“关于”。“关于”页面显示时迹 Logo、版本、版权和
个人开发者信息。

## 11. 常见问题

### 屏幕没有显示，但能听见声音

先短按复位或重新上电一次。若仍无显示，请使用适用于 M5Stack StopWatch 的正式固件
重新安装，不要套用其他 ESP32-S3 设备的固件或分区地址。

### 没有声音或没有粒子音效

检查设置中的声音、音量及音乐律动开关。音乐律动依赖外部声音输入；普通程序音效则
不要求音乐律动开启。

### Wi-Fi 找不到网络

进入 Wi-Fi 页面后等待“网络搜索中”结束，靠近路由器重试。若路由器只使用设备不支持
的频段，请启用兼容的 2.4 GHz 网络。

### 如何清除个人数据

普通设置可在设备上逐项修改；如需完全清除 Wi-Fi 等本地数据，请使用 M5Stack 官方的
擦除与恢复流程。执行前确认已经保存需要保留的自绘图形。

## 12. 安装与恢复

普通用户应通过开发者正式公布的 M5Burner 页面或 Share Code 安装。请确认目标设备为
M5Stack StopWatch，使用数据线并在烧录过程中保持供电。不要自行猜测 Flash 地址。
需要恢复原厂系统时，请使用 M5Stack 官方固件和官方说明。
