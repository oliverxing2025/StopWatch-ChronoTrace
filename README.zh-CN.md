## 当前固件

`1.0.0` 是当前源码版固件。它作为一个独立的 `factory` 应用运行在
M5Stack StopWatch 上，设置、Wi-Fi 凭据和玩家自绘数据保存在设备 NVS 中。

当前固件包含完整的粒子时钟和倒计时体验、40 种内置图形、9 种粒子动画、
最多 12 个玩家自绘图形、音乐驱动的粒子跳跃、设备端 Wi-Fi 配网、缓存天气、
Bluetooth 校时、中英文设置和完整品牌关于页。

本 README 目前不宣称已提供公开 Release 二进制。开发者应从源码编译，并在写入前
核对实体设备身份与实时分区表。

## v1.0.0 更新说明

- **扩展图形库：**40 种内置图形、随机换色、按选择顺序循环播放，以及针对圆屏优化的选择界面。
- **9 种粒子动画：**四个方向箭头、呼吸心跳、DNA 双螺旋、烟花、错位粒子雨和 `I LOVE YOU`。
- **独立粒子队列：**字母和动画结构在运动过程中保留自己的粒子，不再互相借用。
- **真正的音乐律动：**低频、中频和高频驱动粒子上浮、侧向波动、闪光和表层跳跃，而不只是改变颜色。
- **玩家自绘库：**可在设备上保存、换色、播放和删除最多 12 个自定义图形。
- **连接与设备设置：**设备端 Wi-Fi 扫描/密码输入、Bluetooth 校时、天气更新、声音、亮度、震动、音乐律动、操作说明和关于页。
- **完整品牌界面：**开机和关于页使用时迹 Logo，显示个人开发者、版本和版权信息。

### 安全升级方式

| 镜像 | 写入地址 | 适用场景 | 保留内容 |
| --- | ---: | --- | --- |
| `build/stopwatch_chronotrace.bin` | `0x10000` | 更新已核对身份和布局的 ChronoTrace StopWatch | 保留 NVS、bootloader 和分区表 |

> [!WARNING]
> ChronoTrace 使用单个 `factory` 应用分区，不是双应用 OTA 布局。写入前必须
> 识别实体设备并读取实时分区表。先备份 `0x9000` / `0x5000` 的 NVS，然后只把
> 应用镜像写入 `0x10000`。不要套用其他 ESP32-S3 项目的偏移。

## 项目概览

时迹 ChronoTrace 是一个面向 M5Stack StopWatch 的独立粒子交互固件，基于
[V4C38/esp32-fluidbox](https://github.com/V4C38/esp32-fluidbox) 的流体求解器和软件渲染器继续开发。
屏幕中不是预渲染动画：每个粒子都会响应重力、旋转、触摸、当前编队，以及开启后的外部音乐。

| | 能力 | 作用 |
| --- | --- | --- |
| **01** | 实时粒子流体 | 双核物理和软件渲染在 466 × 466 圆形 AMOLED 内运行。 |
| **02** | 时间与姿态 | 使用 BMI270 和 RX8130CE 实现始终正立的数字/模拟粒子时钟。 |
| **03** | 粒子倒计时 | 提供 1–60 分钟圆形选择器、`MM:SS`、暂停/继续和结束反馈。 |
| **04** | 图形与动画 | 40 种图形、9 种动画、随机切换和顺序循环播放。 |
| **05** | 玩家自绘 | 保存最多 12 个自定义图形，每个图形独立保存颜色，可播放和删除。 |
| **06** | 声音与音乐律动 | 生成设备音效，将外部低频、中频、高频映射为真实粒子运动。 |
| **07** | 连接与信息 | 设备端 Wi-Fi 配网、缓存天气、BLE 校时和中英文 UI。 |

## 设备体验

### 粒子时间

- 点击默认界面，粒子组成当前 `HH:MM`。
- 长按锁定时钟；时钟锁定时双击，在数字钟与模拟钟之间切换。
- 倒计时数字变化时保留共用粒子：只从周围流体补入差额，多余粒子按当前重力自然落下。
- 充电时，粒子池中的粒子周期性跃起，在电池下方组成能量线，然后散落再重组。

### 图形库

内置 40 种图形。内置图形每次出现时可使用新的亮色粒子，玩家自绘则保留创作时选择的颜色。

`爱心` `星形` `五角星` `圆形` `方形` `三角形` `菱形` `六边形`
`八边形` `月亮` `无限` `十字` `波浪` `五瓣花` `六瓣花` `八瓣花`
`蝴蝶` `四叶草` `枫叶` `水滴` `闪电` `云朵` `太阳` `彩虹`
`小鱼` `飞鸟` `猫咪` `兔子` `笑脸` `音符` `皇冠` `火箭`
`星球` `雪花` `雨伞` `房子` `大树` `群山` `苹果` `沙漏`

在默认界面向右滑进入图形模式。双击随机换形，长按打开图形选择。
可按顺序选择多个图形循环播放，也可进入自绘界面新增玩家图形。

### 动画库

在图形选择界面向下滑打开动画，向上滑返回图形。

| 动画 | 粒子行为 |
| --- | --- |
| 上 / 下 / 左 / 右箭头 | 逐步组成，穿过近乎整个屏幕直径，到达另一侧后自然散落。 |
| 呼吸心跳 | 心形以快速两段式心跳节奏放大与收缩。 |
| DNA 双螺旋 | 简约双链结构以连续相位变化运动。 |
| 烟花 | 带短拖尾的预组粒子球升空，到达高点后绽放。 |
| 粒子雨 | 多列粒子流以独立位置、相位和速度纵向错位滑动。 |
| `I LOVE YOU` | 各字母使用独立粒子队列浮起并横向滚动，字母之间不借粒子。 |

可识别的编队不会直接变形成另一个图案。ChronoTrace 会先把旧图形释放回真实流体，
让粒子明显松开，再吸引到新图形。

### 音乐律动

音乐律动不只改变颜色：

- 低频脉冲把表层粒子从粒子池向上推起；
- 中频生成交替的侧向波动；
- 高频生成少量闪光和细小喷跳；
- 连续强拍形成更大的分层上浮，同时保留流体重力与碰撞。

律动模式会抑制连续程序化环境音，避免麦克风重复分析设备自身扬声器；
短 UI 音效也有一个短暂的分析保护时间。

### 主要界面说明

| 界面 | 用途 |
| --- | --- |
| 默认流体 | 随倾斜流动的粒子池、主题、程序化声音和音乐律动。 |
| 粒子时钟 | 短时或常显的数字/模拟时间，对当前设备姿态保持正立。 |
| 倒计时 | 圆形分钟选择、粒子数字、暂停/继续和取消。 |
| 图形选择 | 40 种内置图形、玩家自绘、顺序选择、播放、退出和删除。 |
| 动画选择 | 在同一套圆屏界面中选择 9 种粒子动画。 |
| 自绘编辑 | 圆屏练习格、8 种颜色、返回、删除、下一个和确定。 |
| 天气 | 缓存城市、天气图形、当前温度和当日高低温。 |

## 编译与烧录

### 从源码编译

在项目根目录加载 ESP-IDF 并编译：

```sh
. /path/to/esp-idf/export.sh
idf.py set-target esp32s3
idf.py build
```

应用镜像位于：

```text
build/stopwatch_chronotrace.bin
```

正常编译会同时执行 `tools/check_ui_font_coverage.py`。任何新增或修改的中英文 UI 文字，
都需要重新生成 20 px 和 24 px 思源黑体 CN Medium 子集，不要绕过字形覆盖检查。

### 核对实体设备

写入前读取芯片身份、Flash 大小和实时分区表。已验证的 ChronoTrace 布局为：

| 区域 | 偏移 | 大小 |
| --- | ---: | ---: |
| NVS | `0x9000` | `0x5000` |
| factory app | `0x10000` | 15 MB |

普通固件更新前备份 NVS：

```sh
esptool.py --chip esp32s3 --port <PORT> \
  read_flash 0x9000 0x5000 backups/nvs-before-update.bin
```

### 只写入应用

```sh
esptool.py --chip esp32s3 --port <PORT> \
  write_flash 0x10000 build/stopwatch_chronotrace.bin
```

写入后独立校验相同镜像，并检查 115200 baud 启动日志。写入命令成功本身
不代表完整的真机验收。

```sh
esptool.py --chip esp32s3 --port <PORT> \
  verify_flash 0x10000 build/stopwatch_chronotrace.bin
python -m serial.tools.miniterm <PORT> 115200
```

## 操作方式

### 实体按键

| 输入 | 功能 |
| --- | --- |
| A 键短按 | 进入玩家自绘编辑器；编辑时再按取消。 |
| A 键双击 | 打开或关闭 1–60 分钟倒计时选择器。 |
| A 键长按 | 切换 650 / 900 / 1000 粒子密度。 |
| B 键短按 | 切换下一套粒子主题。 |
| B 键双击 | 显示电量与充电状态。 |
| B 键长按 | 开启或关闭外部音乐律动。 |
| A + B 同时长按 | 打开或关闭设置。 |

### 默认界面触控

| 手势 | 功能 |
| --- | --- |
| 点击 | 组成当前粒子时间。 |
| 长按 | 锁定或释放常显粒子时钟。 |
| 双击 | 有时钟时切换数字/模拟钟；否则显示随机图形。 |
| 向左滑 | 打开缓存粒子天气。 |
| 向右滑 | 进入图形模式。 |
| 向上 / 向下滑 | 提高 / 降低扬声器音量。 |

## 配置说明

设置包含两页，可通过滑动或 A/B 键切换：

- **连接设置：** Wi-Fi、设备端网络搜索和密码输入、Bluetooth/时间校准、自动城市天气和中英文。
- **设备设置：** 声音、亮度、震动、音乐律动、操作说明和关于。

BLE 设备名为 `ChronoTrace`。它的自定义 GATT 服务只接收手机时间数据，用于校准
RX8130CE；不接收、不发送玩家自绘或文本。见 [`docs/BLE_PROTOCOL.md`](docs/BLE_PROTOCOL.md)。

## 常见问题排查

### `command not found: idf.py`

在当前终端加载 ESP-IDF 环境：

```sh
. /path/to/esp-idf/export.sh
```

### 设备无法进入烧录模式

确认没有串口监看程序占用 `<PORT>`，确认使用的是 USB 数据线。如果 `/dev/cu.*`
无法完成复位握手，可使用匹配的 `/dev/tty.*` 端口重试。不要把擦除整片 Flash 作为首个排查步骤。

### 烧录后屏幕像死机

先独立校验应用镜像，然后执行硬复位并读取串口日志。重写 bootloader 或分区表
不是应用级更新的常规修复方式。

### Wi-Fi 搜索不到网络

等待异步搜索完成，确认环境中存在 2.4 GHz Wi-Fi，再重新打开设备端网络选择。
ESP32-S3 无法连接只开启 5 GHz 的网络。

### 中文或英文显示替换方框

重新生成两个思源黑体子集并重新编译。已知运行时文字中有任何字符缺失时，
正常编译应直接失败。

### 音乐只改变颜色，粒子不跳

确认音乐律动已开启，设备连续环境音已被抑制，外部声源在麦克风处足够响亮。
低频能量驱动最明显的粒子竖直上浮。

## 隐私

- 固件不包含开发者 Wi-Fi 密码、API Key、固定 Token 或硬编码个人设备标识。
- 用户 Wi-Fi 凭据在设备上输入，仅保存在本地 NVS。
- 开启 Wi-Fi 后，天气功能使用网络位置和 Open-Meteo 数据；关闭 Wi-Fi 会停止这些网络请求。
- BLE 只用于时间校准，不上传自绘、播放列表或音频。

公开源码、二进制、日志或截图前，还应检查本地路径、Git 提交身份、图片元数据、
生成配置和构建产物。

## 当前限制

- M5Stack StopWatch 是唯一支持的硬件目标。
- 本 README 目前不承诺提供面向普通用户的工厂完整镜像或公开 Release 包；
  文档路线是已核对的源码编译与只更新应用。
- 网络和麦克风效果仍依赖真实路由器、环境声学与设备条件。
- 较大的模拟器或内存修改后，需要重新检查长时间动画循环、Wi-Fi/BLE 并行和所有实体朝向。

## 贡献与安全

硬件修改应仅针对 StopWatch，并保留实时 NVS 布局。不要提交凭据、设备备份、
含私密数据的串口日志或本地构建目录。每次 GitHub 推送前，都应执行本地密钥/隐私检查，
并确认仓库 Secret Scanning 与 Push Protection 已开启。

安全敏感问题请私下联系仓库所有者，不要在 issue 中公开凭据或设备数据。
